## Overview

Cloud networks are software-defined, which makes segmentation cheap — and misconfiguration easy.
The goal is **least-privilege connectivity**: only the traffic that must flow, flows.

## Core practices

- **Segment** workloads into private subnets; keep databases off the public internet.
- **Default deny** ingress; allow only required ports and sources.
- **Layer controls** — stateful instance-level rules plus stateless subnet-level rules.
- **Terminate exposure at the edge** — load balancers, WAFs, and private endpoints instead of
  public IPs on workloads.

## How it maps

| Provider | Primitives |
| --- | --- |
