## Overview

Google Cloud security builds on a **resource hierarchy** (organization → folders → projects) with
IAM inheritance, plus Security Command Center for posture and threat detection.

## The essentials

| Area | Services |
| --- | --- |
| Identity | Cloud IAM, IAM Conditions, Organization Policies |
| Detection | Security Command Center, Cloud Logging, Cloud Audit Logs |
| Network | VPC, Firewall Rules, VPC Service Controls, Cloud Armor |
| Data | Cloud KMS, CMEK, DLP |
| Governance | Resource hierarchy, Org Policies |

## Quick wins

- Use the resource hierarchy and Org Policies to set guardrails centrally.
- Enable Security Command Center; review findings.
- Apply IAM Conditions and least-privilege custom roles.
- Use VPC Service Controls to reduce data-exfiltration risk.
