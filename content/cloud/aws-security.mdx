## Overview

AWS security is organized around the **Well-Architected Security Pillar**: identity, detection,
infrastructure protection, data protection, and incident response.

## The essentials

| Area | Services |
| --- | --- |
| Identity | IAM, IAM Identity Center, Organizations + SCPs |
| Detection | CloudTrail, GuardDuty, Security Hub, Config |
| Network | VPC, Security Groups, NACLs, WAF, PrivateLink |
| Data | KMS, S3 encryption + Block Public Access, Secrets Manager |
| Response | Detective, automated remediation via EventBridge |

## Quick wins

- Enable CloudTrail org-wide; turn on GuardDuty.
- Enforce S3 Block Public Access at the account level.
- Use IAM roles, not access keys; apply SCPs as guardrails.
- Encrypt with KMS by default.
