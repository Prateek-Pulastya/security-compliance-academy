## Overview

Azure security centres on **Entra ID** (identity) and **Microsoft Defender for Cloud** (posture and
threat protection), guided by the Microsoft Cloud Security Benchmark.

## The essentials

| Area | Services |
| --- | --- |
| Identity | Entra ID, Azure RBAC, Conditional Access, PIM |
| Detection | Defender for Cloud, Microsoft Sentinel, Azure Monitor |
| Network | VNet, NSGs, Azure Firewall, Private Endpoints |
| Data | Key Vault, Storage encryption, confidential computing |
| Governance | Azure Policy, Management Groups |

## Quick wins

- Enforce MFA and Conditional Access in Entra ID.
- Turn on Defender for Cloud; act on its secure-score recommendations.
- Use Azure Policy to prevent public exposure and enforce encryption.
- Store secrets in Key Vault, not config.
