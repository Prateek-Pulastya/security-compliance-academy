## Overview

**STRIDE** is a threat-enumeration method from Microsoft. For each element of your system, walk the
six categories and ask "can this happen here?" Each maps to a security property.

## The six categories

| Letter | Threat | Violates | Example |
| --- | --- | --- | --- |
| S | Spoofing | Authentication | Forged token or identity |
| T | Tampering | Integrity | Modifying data in transit or at rest |
| R | Repudiation | Non-repudiation | Denying an action with no audit trail |
| I | Information Disclosure | Confidentiality | Leaking data to the unauthorized |
| D | Denial of Service | Availability | Exhausting resources to cause downtime |
| E | Elevation of Privilege | Authorization | Gaining rights beyond those granted |

## How to use it

Apply STRIDE per element of a [data-flow diagram](/threat-modeling/data-flow-diagrams) — each
process, data store, data flow, and external entity. Then map each realistic threat to a mitigation
and a control (see the [Control Explorer](/control-mapping)).
