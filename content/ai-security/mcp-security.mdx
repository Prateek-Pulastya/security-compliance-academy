## Overview

The **Model Context Protocol (MCP)** lets an AI model connect to external **servers** that expose
tools, data, and prompts. Each connected server is a new trust boundary — and a new source of both
capability and risk.

## The risks

- **Prompt/tool injection via server content** — data or tool descriptions returned by a server can
  carry instructions the model follows (a form of indirect
  [prompt injection](/ai-security/prompt-injection)).
- **Excessive agency** — a tool with broad permissions lets a manipulated model take real,
  damaging actions.
- **Supply-chain trust** — a malicious or compromised third-party server.
- **Credential exposure** — tokens the server holds on the user's behalf.
- **Confused deputy** — the model is tricked into misusing its legitimate authority.

## Defenses

- **Least privilege per tool** — grant only the actions genuinely needed; scope tokens tightly.
- **Human-in-the-loop for side effects** — confirm irreversible or outward-facing actions.
- **Vet and pin servers** — treat servers as dependencies; verify provenance.
- **Treat all tool output as untrusted data**, not instructions.
